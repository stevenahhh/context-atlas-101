# 컨텍스트 아틀라스 입문 (Context Atlas 101)

원문 《컨텍스트 아틀라스: 효율적인 에이전트 하네스의 구조》
(<https://stevenahhh.github.io/context-atlas-20261005/>) 를
**처음 보는 사람이 끝까지 막힘없이 읽을 수 있도록 순서를 다시 세워 쓴 학습 자료**입니다.

- 숫자·수식·조건은 원문 그대로 옮겼습니다. 새로 만든 수치는 없습니다.
- 원문이 "실측이 아니다", "단정할 수 없다"라고 밝힌 지점은 여기서도 그대로 밝힙니다.
- 순서는 `왜 → 무엇 → 어떻게` 로 다시 세웠습니다. (원문의 절 번호와 순서가 다릅니다.)
- 15개 장으로 구성되어 있고, 일부 장에는 원문의 계산식을 그대로 재현한 대화형 실험이 들어 있습니다.

## 만들기

```bash
bun install
bun run build.ts     # content/*.md → index.html (단일 파일, 외부 의존 없음)
```

`index.html` 하나에 CSS·JS·데이터가 모두 인라인되어 있습니다. 별도 서버나 CDN 없이 열립니다.

## 구성

```
content/     장별 원고 (마크다운)
src/style.css
src/app.js   대화형 실험 (임계값 실험실, 히스테리시스, 세션 재생)
src/figures.ts
src/data/    원문 페이지에서 추출한 실측 세션 데이터
build.ts     정적 사이트 생성기
BRIEF.md     집필 규칙 (용어집·형식)
_source/     원문에서 추출한 장별 텍스트 (집필 참고용)
```
